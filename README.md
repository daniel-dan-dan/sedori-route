## v209 ブランド図鑑の自動更新

- 図鑑を開いたときと、表示中15分ごとに認証付きで最新版を確認します。接続済み端末ではファイル選択不要です。

- 更新画面から再確認できます。手動取り込みは復旧用の折りたたみ欄に残します。
- 端末内の図鑑DBと既存資料は維持します。新規資料の調査を自動実行するものではありません。
- 2026-09-14: 非公開Driveの配信設定、実資料1件の取得テスト、GAS @63 公開を完了。PWA v209 は自動更新に対応します。今後は同じ非公開配信ファイルを更新すれば、アプリ再公開なしで反映されます。PDFのみの変更では配信内容は更新されません。

店舗選択、選択順ルート、Google Mapsナビ、仕入れ記録、巡回履歴、分析をスマートフォンで扱うPWAです。

## 安全設計

- GAS接続コードと端末専用鍵は専用IndexedDBへ保存し、localStorageや画面へ露出しません。
- CSPで同一配信元以外のスクリプトとinline scriptを遮断します。
- 外部データを地図ポップアップへHTML文字列として挿入しません。
- 書込前にoperation IDと本文をIndexedDBへ保存します。同じ在庫・内容の未確定受付があれば、新しいIDで送信しません。
- サーバーは書込開始前に受付を保存し、応答記録に失敗した受付を二重実行しません。結果不明、7日超、12回失敗した項目は自動再送を停止します。結果不明は受付IDから個別に照合してください。
- 店舗の候補が1件でも自動書戻しせず、選択後に在庫UUID・変更前の店名・仕入日を比較します。在庫の読み込み失敗時は優先度を空集計で上書きしません。
- 距離と時間は直線距離による概算です。1店舗でも滞在時間を含み、0分も有効です。道路・混雑・営業時間は未反映です。
- v197の新規在庫登録は、在庫正本側の専用受付へ同じ受付IDで送信し、在庫UUID・内容hash・読戻し済み応答が一致した時だけ成功とします。専用キーは両GASのScript Propertiesに保存し、端末には渡しません。
- 2026-09-05時点: v197はローカル実装・回帰試験済みです。専用キーの設定と実GASの隔離単品試験が未完了のため、この時点では公開v196/@60を変更していません。これは承認待ちではなく設定・検証待ちです。
- v198はPWAのUI更新です。GAS bridgeの公開・専用キー設定・実GAS登録試験は含みません。画面のv198表示を在庫正本連携の完了証拠にしないでください。

## v198で導入した画面（地図ピンはv202で上記へ変更）

- 地図と店舗一覧を切替可能。店舗名・地域・住所の複数語検索、選択店舗の順番表示に対応します。地図が失敗しても一覧から選べます。
- ルート確認で上下移動と「外す」ができ、距離・Google Mapsの区間も再計算します。店舗マスタは削除しません。
- 仕入れは商品名・仕入価格を先に入力し、任意項目を折りたたみます。「登録してもう1点」は受付完了・送信待ちを確認した後に次の入力へ移ります。
- 入力は専用の端末内下書きへ自動保存。送信中は閉じる・再送を止め、結果不明や登録後の端末整理失敗でも受付IDを保持します。
- 巡回と「その他」で、この端末の受付から「在庫登録済み／送信待ち／要確認」と商品明細を表示します。既存の過去登録を遡って確定する表示ではありません。登録済みはAPI成功応答の登録行が確認できた商品だけです。
- 下部はルート・履歴・分析・ブランド図鑑・その他の5項目。クイズと設定への既存hashは保持します。設定は接続・出発地点・店舗管理・詳細・履歴消去に分けて開けます。
- 更新は全タブを閉じた後に適用します。自動再読込や旧タブからの即時切替要求で入力画面を消しません。

### v203 地図の提供元をCARTO Voyagerへ復元

- メイン地図と店舗追加の地図を、以前のCARTO Voyagerの色・道路表示に戻します。店舗ごとの36pxロゴピン、選択順番号、Google Mapsナビは維持します。
- 取得済みキーはGASのScript Properties `CARTO_BASEMAP_API_KEY`で管理し、認証付き`getConfig`から接続済み端末へ渡します。公開ソース・configシートへキーを保存しません。端末では既存のIndexedDB設定キャッシュを使用します。ブラウザからのタイル通信には仕様上キーが含まれます。
- キー未取得時は透かし付きの要求を送信せず、店舗一覧を使える案内を出します。設定がバックグラウンドで届くと、地図だけを更新します。別の地図提供元への自動切替はしません。
- CARTOとOpenStreetMapの出典を表示し、タイルはCARTOへ直接要求します。Service Workerには保存しません。
- [公式案内](https://carto.com/basemaps/apikey/)の無料枠は月500万タイルです。有料契約やカード登録は行っていません。恒久無料・無停止は保証されません。
- [規約第14条](https://carto.com/legal/basemap-terms/)には走行中の車両での地図表示等への制限があります。停車中の店舗選びに使い、ナビは別のGoogle Mapsで開きます。APIキー取得が走行中の利用許可を意味するものではありません。
- v203は地図の復元のみで、未公開の在庫登録連携やほかのGAS変更を公開するものではありません。

## 独立したブランド図鑑アプリ

ブランド図鑑は `https://daniel-dan-dan.github.io/sedori-route/brand-guide/` から単独起動・ホーム画面追加できます。店舗アプリのアイコンとは別になります。

`brand-guide/` に専用manifest・アイコン・起動処理・接続設定・Service Workerを置き、閲覧部品 `brand-guide.js` と読み取り配信 `brand-guide-sync.js` を共用します。図鑑専用キャッシュ以外は削除しません。資料の保存先と非公開配信元を維持し、既存ブラウザの接続を一度読み取って図鑑専用DBへ引き継ぎます。新規端末の接続登録は既存GAS契約を使用します。

独立アプリの変更時は、専用画面の版数・manifest内の起動URL・専用SWの版数・全assetのcache bustを照合してください。共有の閲覧・配信部品を変える場合は独立アプリの版数も更新します。店舗PWAのSWを変えた場合は店舗側の版数も更新します。

## v228 店舗完了の保存待ちを短縮（2026-10-01）

- 巡回画面の表示時に変更前の店舗状態を事前取得し、同じ巡回の全店舗分を通信中だけ保持します。通常の完了操作では一覧取得を挟まず、保存要求だけを送ります。
- 事前取得と完了操作の同時読込は1要求へまとめます。遅れて届いた読込が保存後の確認値を上書きしないようにします。
- サーバーの変更前状態との比較、受付ID、二重送信の防止、成功応答確認後の画面移動は維持します。他端末で変更された場合は保存せず再確認します。事前取得失敗だけでは書込受付を作りません。
- GASの本番設定やコードは変更しません。実際の保存時間は通信状態とGASの処理時間に依存します。
