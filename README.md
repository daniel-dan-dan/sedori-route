# 店舗巡回ルートPWA

店舗選択、選択順ルート、Google Mapsナビ、仕入れ記録、巡回履歴、分析をスマートフォンで扱うPWAです。

## 安全設計

- GAS接続コードと端末専用鍵は専用IndexedDBへ保存し、localStorageや画面へ露出しません。
- CSPで同一配信元以外のスクリプトとinline scriptを遮断します。
- 外部データを地図ポップアップへHTML文字列として挿入しません。
- 書込前にoperation IDと本文をIndexedDBへ保存します。同じ在庫・内容の未確定受付があれば、新しいIDで送信しません。
- サーバーは書込開始前に受付を保存し、応答記録に失敗した受付を二重実行しません。結果不明、7日超、12回失敗した項目は自動再送を停止します。結果不明は受付IDから個別に照合してください。
- 店舗の候補が1件でも自動書戻しせず、選択後に在庫UUID・変更前の店名・仕入日を比較します。在庫の読み込み失敗時は優先度を空集計で上書きしません。
- 距離と時間は直線距離による概算です。1店舗でも滞在時間を含み、0分も有効です。道路・混雑・営業時間は未反映です。
- v197の新規在庫登録は、在庫正本側の専用受付へ同じ受付IDで送信し、在庫UUID・内容hash・読戻し済み応答が一致した時だけ成功とします。専用キーは両GASのScript Propertiesに保存し、端末には渡しません。
- 2026-09-05時点: v197はローカル実装・回帰試験済みです。専用キーの設定と実GASの隔離単品試験が未完了のため、この時点では公開v196/@60を変更していません。これは承認待ちではなく設定・検証待ちです。
- v198はPWAのUI更新です。GAS bridgeの公開・専用キー設定・実GAS登録試験は含みません。画面のv198表示を在庫正本連携の完了証拠にしないでください。

## v198の画面

- 地図と店舗一覧を切替可能。店舗名・地域・住所の複数語検索、近接店舗の件数表示、選択店舗の順番表示に対応します。地図が失敗しても一覧から選べます。
- ルート確認で上下移動と「外す」ができ、距離・Google Mapsの区間も再計算します。店舗マスタは削除しません。
- 仕入れは商品名・仕入価格を先に入力し、任意項目を折りたたみます。「登録してもう1点」は受付完了・送信待ちを確認した後に次の入力へ移ります。
- 入力は専用の端末内下書きへ自動保存。送信中は閉じる・再送を止め、結果不明や登録後の端末整理失敗でも受付IDを保持します。
- 巡回と「その他」で、この端末の受付から「在庫登録済み／送信待ち／要確認」と商品明細を表示します。既存の過去登録を遡って確定する表示ではありません。登録済みはAPI成功応答の登録行が確認できた商品だけです。
- 下部はルート・履歴・分析・廃盤・その他の5項目。クイズと設定への既存hashは保持します。設定は接続・出発地点・店舗管理・詳細・履歴消去に分けて開けます。
- 更新は全タブを閉じた後に適用します。自動再読込や旧タブからの即時切替要求で入力画面を消しません。

## 確認

### v199 Amazon価格管理（先行公開）

ホーム上部の「Amazon価格管理」から、Amazon商品をSKU・ASIN・商品名で探し、現在価格／目安価格／見込み利益／参考下限価格／判断理由／次回確認日を確認できます。参考下限は候補価格時点の手数料を固定した参考値で、利益を保証する最低価格ではありません。最初の導入は `suggestion_only` で、Amazonへの価格変更ボタン・自動価格変更はありません。数値不明は0円にせず「未確認」と表示します。

先行公開では販売履歴と実際の販売開始日が未接続のため、価格目安・見込み利益は保留します。現在価格・在庫数・取得日時と、通常/大型の追加費用区分を確認できます。通常は1点0円、大型は1点1,000円を追加費用として設定し、Amazon販売手数料・FBA配送手数料は別計算です。商品区分が不明な場合は0円にしません。期限切れ・キャッシュ・オフラインの数量は「前回確認」の参考値として表示します。

- 「3日／7日様子を見る」「対象外」「対象に戻す」は、接続済み・新しいデータ・変更前revisionを確認できる場合のみ保存します。API応答後に一覧を読み戻して結果を確認します。
- 保存前に端末へ受付記録を保存し、結果不明時は自動再送を行いません。再読み込み後も受付記録を残し、一覧との一致を確認できるまで設定変更を停止します。
- 一覧はIndexedDBへ保存します。オフライン・24時間到達・取得失敗のデータは閲覧のみで、現在価格だけ前回参考表示とし、提案額・利益・参考下限は隠します。商品のvalidUntilが欠損・不正・到達した提案も金額を隠して再取得を促し、期限到達時は画面を自動再描画します。接続未設定と対象0件を区別します。
- 対象は在庫管理シートの未販売Amazon SKUで、未紐付のAmazon出品は含まないことを併記します。DOMは50商品単位の前後ページ切替に制限します。
- 画面の時刻は日本時間です。見直し日は販売完了の予測・保証ではありません。
- `api.js` の `getAmazonPricing` / `updateAmazonPricingPreference` を使います。既存の在庫登録経路は変更していません。

```bash
node --test *.test.mjs
node verify-pwa-version.mjs
```

公開前後の画面確認は [MOBILE_RELEASE_CHECKLIST.md](MOBILE_RELEASE_CHECKLIST.md) に従います。
